# Examples

This is an interactive program with no file-based input or output; see the user documentation for instructions on how to run it and what the controls do.

The combatants present in any given run are defined in `CombatantSetup.cs` rather than supplied as external data, so "example input" in the traditional sense does not apply here. The user documentation explains how to edit that file to change which combatants appear in a fight.
